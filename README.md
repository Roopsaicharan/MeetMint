# MeetMint

## Project Description
MeetMint is a full-stack web application that converts meeting notes or transcripts into structured, trackable action items. It generates a concise meeting summary (decisions, blockers, next steps) and extracts tasks with suggested owners and due dates, then allows teams to confirm and manage them on a Kanban board with reminders and task-level chat (public/private). The goal is to reduce coordination time and keep teams aligned after meetings.
